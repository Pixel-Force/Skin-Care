# Skin Care — Clinical Dermatology & Aesthetic Skincare HTML5 Template

A clean, modern, standalone 10-page HTML5, CSS3, and Vanilla JavaScript website template built for clinical dermatology studios, skincare specialists, and aesthetic medicine practices.

## Pages Included
- `index.html` — Homepage with hero gradient showcase, patient trust card, asymmetric about & vision split, featured services, clinic working hours, specialist cards, interactive community testimonials, and consultation CTA
- `about-us.html` — Clinic philosophy, 6 core pillars, animated dermatology expertise meters, interactive branch switcher with map embed, and awards
- `services.html` — Full 6-treatment clinical catalog, Why Choose Us pillars, and 3-step care journey
- `service-details.html` — Dynamic treatment detail view (`?service=...`), clinical highlights, protocol overview, and verified patient reviews
- `doctors.html` — Board-certified dermatologist profiles with direct specialist booking
- `pricing.html` — Interactive Monthly Care Plan / Single Session toggle across 3 flexible skincare packages
- `appointment.html` — Full-page scheduling form, working hours, and local reservation history
- `help-center.html` — Searchable Patient & Doctor FAQ accordions and support overview
- `contact-us.html` — Clinic contact cards, direct inquiry form, and branch access
- `404.html` — Clean fallback page

## Key Features
- **Global "Book Appointment" Popup Modal** — Accessible from every CTA button across all pages with preselected treatment/doctor support, interactive time-slot picker, validation, confirmation summary with reference ID, and `localStorage` booking persistence.
- **Global Search Overlay** — Instant filtering across treatments, doctors, packages, and clinic pages.
- **Zero External Build Dependencies** — Pure semantic HTML5, modular CSS (`assets/css/style.css`), and Vanilla JS (`assets/js/data.js`, `assets/js/app.js`).
